The node release for the public merged-mining testnet (#13, [SIP-0003](../proposals/SIP-0003-public-testnet.md)).
Prepared 2026-11-24 as a release candidate; **nothing is published**. The day's steps are in the
[go runbook](v0.2.0-testnet.1-go.md); the release text in [v0.2.0-testnet.1-notes.md](v0.2.0-testnet.1-notes.md).

## Release shape (decided in the kit design, applied here)

| Question | Answer | Why |
|---|---|---|
| Version | `0.2.0-testnet.1` in `sedra_release()`; archive `sedra-rusty-0.2.0-testnet.1-linux-amd64.tar.gz` | DESIGN.md 3.1; "testnet" is in the version, the file name and `kaspad --version` |
| Tag | `sedra-v0.2.0-testnet.1`, signed by Nec like v0.1.x | the `sedra-` prefix avoids upstream's own `v*` tags (`docs/RELEASE.md`) |
| Branch | `release-0.2.0-testnet.1`, cut from `testnet-kit` with `main` merged in; `testnet-kit` was fast-forwarded to it on 2026-11-24 and then got the status page (operator tooling, not part of the release) | RUNBOOK 3.2: never on `main`, which holds mainnet releases; never merged into `main` or `dev` |
| GitHub | **pre-release**, not "latest" | "latest" keeps pointing at the mainnet release 0.1.1 |
| Mainnet safety | the binary refuses to start without `--testnet` (or `--devnet`, `--simnet`) | added in this release: the default network of `kaspad` is mainnet, so a testnet binary started without flags would otherwise run as a mainnet node |
| Network | `sedra-testnet-10`: own network name, genesis, ports and address prefix; peers from another network are refused in the handshake | DESIGN.md 1 (**Verified** in the code 2026-11-20) |

## Release day

## If something goes wrong

- Checksums differ across machines: no release; investigate (`docs/RELEASE.md`, "If your checksum differs").
- A test fails: no release; fix on the release branch, rebuild both machines.
- The rehearsal fails: the tag is not pushed; fix, `0.2.0-testnet.2`, the launch moves.

## What this does NOT mean

- A release candidate is not a release: nothing is tagged, signed or published.
- It does not launch the testnet or set a date; that waits for the Sedra team's yes and Nec's go.
- Nothing here changes Sedra mainnet.
