withdrawn public release. Publishing on 11-30 still meets the team's condition that the binaries are public before
the launch (Q51, 2026-11-23 working draft). If the rehearsal fails: no push; fix, `0.2.0-testnet.2`, launch moves.

## 1. Tag text (AI, in WSL)

```
cd ~/repos/sedra-rusty
C=24511407f15734d2b7b0daa0403f3b1edd4e1ed4
OUT=~/release-prep-0.2.0-testnet.1
{
  printf 'object %s\ntype commit\ntag sedra-v0.2.0-testnet.1\n' "$C"
  printf 'tagger Nec <241580569+necatgit@users.noreply.github.com> %s +0000\n\n' "$(date +%s)"
  printf 'sedra-rusty 0.2.0-testnet.1: public testnet only (sedra-testnet-10); refuses to run on mainnet\n\n'
  printf 'SHA256SUMS (container build, identical on two machines):\n'
  cat "$OUT/SHA256SUMS"
} > "$OUT/sedra-v0.2.0-testnet.1.tagtext"
cat "$OUT/sedra-v0.2.0-testnet.1.tagtext"
```

`$OUT/SHA256SUMS` is the candidate's file (below, "Checksums"). Copy the `.tagtext` file to the key's machine.

## 3. Local tag, verify, rebuild from it (AI, in WSL)

```
cd ~/repos/sedra-rusty
OUT=~/release-prep-0.2.0-testnet.1
T=$(cat "$OUT/sedra-v0.2.0-testnet.1.tagtext" "$OUT/sedra-v0.2.0-testnet.1.tagtext.sig" | git mktag)
git update-ref refs/tags/sedra-v0.2.0-testnet.1 "$T"
git -c gpg.ssh.allowedSignersFile=$HOME/allowed_signers tag -v sedra-v0.2.0-testnet.1   # must say: Good "git" signature
git rev-parse sedra-v0.2.0-testnet.1^{commit}                                            # must be the candidate commit
# fresh clone of the local tag, container build, same checksums as the candidate
rm -rf ~/build-sedra-v0.2.0-testnet.1 && git clone -q ~/repos/sedra-rusty ~/build-sedra-v0.2.0-testnet.1
cd ~/build-sedra-v0.2.0-testnet.1 && git checkout -q sedra-v0.2.0-testnet.1 && contrib/reproducible/build-in-docker.sh
diff dist/SHA256SUMS "$OUT/SHA256SUMS" && echo IDENTICAL
```

Any difference or a bad signature: stop, nothing is pushed.
