# sedra-rusty v0.1.0: release notes (draft)

> Draft for 2026-11-14. Two values are filled in on release day and marked **[release day]**: the final M9 result and
> the test count of the release commit. Published as the GitHub release text, without this note.

## What this is

A full node for the Sedra network written in Rust, built on rusty-kaspa v1.0.1. It follows **exactly the same
consensus rules as Sedra's Go node `sedrad` v2.0.0**, including both relaunch rules (the difficulty reset and the
treasury outputs). It runs next to Go nodes on the same network; nothing changes for anyone who does not run it.

It is the first independent implementation of Sedra's rules: if one implementation has a bug, the other one shows it.

## What this is not

- **No fork and no new rules.** Merged mining (SIP-0001) is developed separately and is **not** part of this
  release. It will only ever be activated after a public testnet and a date agreed with the Sedra team.
- Not an official release of the Sedra team.

Security fixes from later rusty-kaspa releases are included where they apply to Sedra; each is listed with its upstream
commit and its regression test in `SEDRA.md`. One upstream change was deliberately not taken over: it rejects real
Sedra pruning proofs.

## Verify before you run it

1. **Checksum:** compare the archive with `SHA256SUMS`.
2. **Signature:** the tag `sedra-v0.1.0` is signed by Nec (fingerprint `SHA256:Eh/4CtYZPvHjYldtNexGX4RLCsz/Mi5MsBZDLKTRvUc`,
   published at <https://puddlepool.com/keys.html>):
   `git -c gpg.ssh.allowedSignersFile=allowed_signers verify-tag sedra-v0.1.0`
3. **Rebuild:** the build is reproducible; `docs/RELEASE.md` explains how to get the same bytes yourself. Independent
   rebuilds are welcome as a comment on the release issue.

## Running it

- Linux amd64. The binary keeps its upstream name `kaspad`; `kaspad --version` prints `0.1.0`, the upstream base and
  the commit.
- Mainnet is the default; ports 22110 (RPC) and 22111 (P2P), as with sedrad.
- For wallets, pools and explorers start it with `--utxoindex`; Sedra's Go wallet connects with
  `--rpcserver=<node>:22110`.
- Never expose the RPC port to the internet.

## Known limits

- One platform (Linux amd64) and one maintainer.
- Peers see the upstream user agent `kaspad:1.0.1`, so the network cannot yet tell this node apart from others.

## Reporting problems

Bugs: GitHub issues. Security problems: privately, as described in `SECURITY.md`.
