# Research archive

Unedited originals of research reports, kept for later reference. Each file is saved exactly as it was produced,
named `YYYY-MM-DD-NNNN-short-name-raw.md`.

The reviewed versions in [research/](../) are what the project relies on. Comparing the two shows what was
corrected or removed during review, and why.

Notes for readers:

- References marked `@mc` point to the Miningcore pool code run by Nec (PuddlePool). That repository is not public,
  so those references cannot be checked from outside.
- Files here are never edited after they are added. Corrections go into the reviewed version.
- One raw report is held privately instead of published, because it spells out how to trigger crash bugs that may
  still be unpatched on other networks: [2026-11-06-q31-backports-held-private.md](2026-11-06-q31-backports-held-private.md)
  (since 2026-11-17).
